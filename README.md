### How I work with AI

AI writes code quickly. The engineering is in deciding what it should write and proving that it's right.

1. **Spec first.** Work starts from a written spec. Where a detail is unclear, the options get listed, not guessed.
2. **Controlled delegation.** Larger tasks are split into focused Claude Code sessions with explicit briefs, only the context they need, and no overlapping files.
3. **Rules in writing.** A `CLAUDE.md` in each project sets out the architecture and safety rules.
4. **Tests first where it matters,** and tests are never weakened to make them pass.
5. **Build, test and review before every commit,** in small, reviewable changes.
